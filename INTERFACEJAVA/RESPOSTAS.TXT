Qual é a diferença entre os métodos sobrecarregados?
Os métodos sobrecarregados tem o mesmo nome e pertencem à mesma classe, mas são diferentes no número ou no tipo dos parâmetros que recebem 
EXEMPLO: um método pagar(valor) aceita apenas o valor, enquanto pagar(valor, chavePix) aceita o valor e uma String adicional

Explique com suas palavras a função de uma interface em Java.
Uma interface funciona como um contrato obrigatório. Ela mostra quais métodos as classes devem ter, fazendo que diferentes tipos de objetos compartilhem as mesmas ações, mas deixando que cada classe implemente a lógica interna dessas ações do seu próprio jeito.
